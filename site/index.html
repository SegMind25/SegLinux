01 — Features

Everything a gamer needs, nothing it doesn't.

Install

Installs like Windows

Setup asks for your language, disk and account, shows exactly what it will do, then installs. Answer files work like autounattend.xml.

Desktop

A desktop written in Rust

Floating dock, Start menu with search, desktop icons, tray and calendar, on the labwc Wayland compositor. 59 MB of memory at idle.

Gaming

Built for gaming

linux-zen kernel, Steam with Proton, Lutris, GameMode, MangoHud and gamescope, NTSYNC, zram and a Steam Gaming Mode session.

Windows apps

Double-click an .exe

segrun inspects the program and prepares Wine for it, with DXVK and VKD3D-Proton for Direct3D, and runs games under GameMode.

Low-end PCs

Light on old hardware

A 740 MB Lite image, compressed swap in memory, tuning for Intel graphics and a desktop that leaves the CPU and GPU to your game.

System

No systemd

OpenRC with parallel start by default; runit and dinit builds too. A rolling release with up-to-date packages.

      04 — Get started

      From download to desktop in four steps.

      1. 1

        Download and check

        Lite downloads as one ISO. For Full, use the automatic helper or follow the download guide to join the parts and verify them.

        python3 download-full.py
      2. 2

        Write it to a USB stick

        With Ventoy, Rufus (in DD mode) or, on Linux:

        sudo dd if=seglinux.iso of=/dev/sdX \
  bs=4M status=progress oflag=sync
      3. 3

        Boot from it

        Turn off Secure Boot in the firmware settings, start the computer from the USB stick and choose Start SegLinux.

      4. 4

        Install

        Try the desktop, then double-click Install SegLinux. Setup takes 10 to 40 minutes; Lite needs the internet.

      Good to know

      • Games whose anti-cheat needs a Windows kernel driver do not run on Linux, on SegLinux or elsewhere.
      • Secure Boot must be off: the boot chain is not signed with Microsoft's key.
      • Setup erases the whole disk you choose. Copy your files elsewhere first.
